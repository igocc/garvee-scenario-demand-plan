3路线 A：先找场景

核心是把场景词收全：长尾词和 AI 两路取并集，再用用户、社区、竞品来源补漏。

步做什么示例
A1建产品核心词表：从 GARVEE SKU 标题抽取核心词，再用类目名称判定归属，合并去重。每个类目保留 1–2 个主词，按 GMV 排序PHO_11X77DCV 标题 → hydraulic dog grooming table → 主词 dog grooming table
A2多源收集场景词，取并集（见下表）shelving for a garage → garage
A3归一去重；至少 2 类来源都出现才保留。AI 独有的词要补到搜索量或用户来源才保留in the garage / for garage → garage
A4建“场景 × 品类”矩阵；横跨 ≥ 3 个 GARVEE 品类且需求靠前 → 候选场景，交给路线 Bgarage → 货架、举升机、地板、空调…

类型来源怎么拿示例

5共购验证

搜索结果里一起出现，不等于真的会一起买。套装上架前必须过这一步。

数据源证明什么费用状态
Shopify 订单自家同单、同客 90 天共购免费待开权限
Amazon 购物篮分析自家 ASIN 前 3 共购及比例免费，需品牌备案待确认备案
Apify 竞品“一起买”竞品怎么搭（算法推荐，无比例）$2–4 / 千商品待批准
Keepa同上，带历史约 €49 / 月起首期不用
每个组合算含义
共购单数太少就标“无数据”，不硬上
A→B 附加率买 A 的人中也买 B 的比例
B→A 附加率反方向，常不对称
提升度 lift> 1 才说明比随机更常一起买
大件商品同单共购少，所以同时看“同一客户 90 天内先后买”。共购门槛第 2 周看完数据分布后再定，不预设。
